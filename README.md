# 🌱 KrishiAI – AI-Powered Agricultural Assistant

Hi everyone! 👋

I'm building **KrishiAI** as part of the TrainWithShubham DevOps Hackathon. The idea behind this project is to use AI to help Indian farmers understand crop problems and get basic agricultural guidance in a simple way.

I'm also using this project to learn and implement DevOps tools and cloud technologies while building a real application.

## 🚜 Why KrishiAI?

Farmers may face problems with crop diseases, yellowing leaves and other crop-related issues. Getting the right guidance at the right time can be difficult.

With KrishiAI, my goal is to let farmers describe a crop problem or upload a photo and receive AI-generated guidance in their preferred language.

## ✨ Features

- 🌱 Enter a crop name and describe the problem.
- 📷 Upload a crop image for AI-based analysis.
- 🤖 Get possible causes and suggested actions.
- 🌿 Receive preventive measures for crop problems.
- 🌐 Use the application in English, Marathi or Hindi.
- 📱 Access a simple, mobile-friendly interface.

I'm still working on improving the application, and I plan to add more useful features as the project develops.

## 🏗️ How It Works

The basic workflow is:

1. The farmer opens the KrishiAI web application.
2. They enter a crop name, describe the problem, upload an image, or provide a combination of these inputs.
3. The frontend sends the information to the FastAPI backend.
4. The backend sends the request to the Gemini API for analysis.
5. The generated guidance is displayed to the farmer in the selected language.
